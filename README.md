# 밀양손씨 목사공파 가계도

친인척 관계 정리용 가계도 웹앱. 단일 HTML + Supabase.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (트리·촌수 엔진·편집·Supabase 연동) |
| `schema.sql` | Supabase DB 스키마 + RLS + 편집자 관리 함수 |
| `supabase-설정.md` | 서버 연동 단계별 가이드 |
| `배포방법.md` | Vercel/Netlify 배포 안내 |
| `vercel.json` | 검색엔진 차단 등 배포 헤더 |
| `robots.txt` | 검색엔진 차단 |

## 주요 기능

- **촌수·호칭 자동 계산** — 한국식 호칭, 8촌 친족 범위 표시
- **가로식 / 세로식** 트리 — 드래그로 부모 변경(자손 세대 자동 재계산)
- **미상(?) 노드 1급 지원** — 서열만 아는 경우도 기록, 미상 순회
- **관련 정보 패널** — 자손 수, 세대 분포, 직계 계보, 공통 조상
- **데이터 직접 편집** — 표 형태, 순환 참조·FK 검증
- **Supabase 연동** — 보기는 누구나 / 편집은 등록된 사람만(카카오·이메일)
- **백업** — JSON 내보내기/불러오기, 저장 실패 감지

## 동작 모드

- **오프라인**: `SB_URL`/`SB_KEY` 비우면 localStorage만 사용
- **서버**: 두 값 채우면 Supabase 동기화 (모든 기기 공유)

## 데이터 출처

구글시트로 관리하던 36~42대 가계도를 이관. 36대 '손사익'은 미확인(추정) —
세대 연대·파 불일치로 대동보 대조 필요. 상세는 앱 내 시조 메모 참고.
